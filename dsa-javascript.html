How to learn

The only loop that works

DSA is not a spectator sport. For every lesson: predict on paper → type in JS → break it with an edge case → say time and space. Reading this HTML without a keyboard will not make you expert.

  1. Draw the data (boxes and arrows). JS references are arrows.
  2. Write the function without looking at the solution.
  3. Run 3 cases: empty, one element, the ugly case (duplicates, cycles, negatives).
  4. Only then reveal. Diff your code. Steal one idea, rewrite from blank.
From scratch vs built-in. You implement a linked list so you understand pointers. In production you use Array and Map unless you need the pointer structure (LRU, explicit nodes). Interviews want both: you can write it, and you know when not to.

The language

JS as a machine

DSA in JS is pointer-and-array thinking with a garbage collector. Learn the costs, then forget micro-optimizing V8.

Values, references, and why mutations surprise you

JavaScript values are either primitives (number, string, boolean, null, undefined, symbol, bigint) or objects (arrays, functions, maps, your nodes). Assignment of a primitive copies the value. Assignment of an object copies the reference — another arrow to the same box.

JavaScript
let a = 1;
let b = a;
b = 2;
// a is still 1

const x = { n: 1 };
const y = x;
y.n = 2;
// x.n is 2 — same object

function bump(obj) {
  obj.n += 1;          // mutates caller
  obj = { n: 0 };      // rebinds local only
}

This is why linked-list and tree code is “pointer” code even though JS has no *. A node is an object. curr.next = prev redirects an arrow.

stack (names) heap (objects) head ──────────────► { val: 1, next: ──► { val: 2, next: null } } curr ──────────────┘
Arrays are objects. const a = b does not copy elements. [...b] or b.slice() is a shallow copy — nested objects are still shared.

Big O

If n doubles, what happens?

Big O is how work grows, ignoring constants. Interviewers want you to read your loops.

function sum(a) {           // O(n) time, O(1) extra space
  let s = 0;
  for (const x of a) s += x;
  return s;
}
function hasDupNaive(a) {   // O(n²)
  for (let i = 0; i < a.length; i++)
    for (let j = i + 1; j < a.length; j++)
      if (a[i] === a[j]) return true;
  return false;
}
function hasDup(a) {        // O(n) time, O(n) space
  const seen = new Set();
  for (const x of a) {
    if (seen.has(x)) return true;
    seen.add(x);
  }
  return false;
}

Space: extra arrays, maps, and recursion depth count. The input itself is usually not “extra.” Recursion depth of n is O(n) stack space.

n = 106. O(n) is fine. O(n log n) is usually fine. O(n²) is not. Say this out loud when you pick an approach.

Foundation

Arrays

The array is a numbered shelf

A JS array is an ordered list of slots 0..length-1. Index is O(1). Insert/delete at the front is O(n) because every index after the hole must move.

[ 10 | 20 | 30 | 40 ] 0 1 2 3 unshift(5) → move all right → O(n) push(50) → write at end → amortized O(1)
JavaScript
function indexOf(arr, target) {
  for (let i = 0; i < arr.length; i++) if (arr[i] === target) return i;
  return -1;
}

function reverseInPlace(arr) {
  let lo = 0, hi = arr.length - 1;
  while (lo < hi) {
    const t = arr[lo];
    arr[lo] = arr[hi];
    arr[hi] = t;
    lo++;
    hi--;
  }
  return arr;
}

function reverseRange(arr, lo, hi) {
  while (lo < hi) {
    [arr[lo], arr[hi]] = [arr[hi], arr[lo]];
    lo++;
    hi--;
  }
}

function rotateRight(arr, k) {
  const n = arr.length;
  if (!n) return arr;
  k %= n;
  reverseRange(arr, 0, n - 1);
  reverseRange(arr, 0, k - 1);
  reverseRange(arr, k, n - 1);
  return arr;
}

Two-array pattern: build out with push when you cannot mutate. In-place when the interviewer asks for O(1) extra space.

Holes: arr[100] = 1 on a short array makes a sparse array. Interview code should stay dense. Prefer push over assigning far indexes.

Foundation

Strings

Strings are immutable sequences

You cannot assign s[i] = 'x' and have it stick. Build a new string or use an array of characters. For interviews, convert with s.split('') when you need random access writes — know that is extra O(n) space.

JavaScript
function isPalindrome(s) {
  const t = s.toLowerCase().replace(/[^a-z0-9]/g, "");
  let lo = 0, hi = t.length - 1;
  while (lo < hi) {
    if (t[lo] !== t[hi]) return false;
    lo++;
    hi--;
  }
  return true;
}

function reverseWords(s) {
  return s.trim().split(/\s+/).reverse().join(" ");
}

Code units: s.length and s[i] are UTF-16 units. Emoji can be two units. For interview ASCII problems this is fine; for real i18n use [...s] or Intl.

Object vs Map vs Set

A hash table maps key → value in average O(1). In JS:

function twoSum(nums, target) {
  const seen = new Map(); // value → index
  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i];
    if (seen.has(need)) return [seen.get(need), i];
    seen.set(nums[i], i);
  }

}

function firstUniqueChar(s) {
  const freq = new Map();
  for (const ch of s) freq.set(ch, (freq.get(ch) || 0) + 1);
  for (let i = 0; i < s.length; i++) if (freq.get(s[i]) === 1) return i;
  return -1;
}

Pointers

Linked lists

A list is nodes and arrows

Each node holds a value and a reference to the next node. The list is the head. There is no index — walking is O(n). Insert/delete at a known node is O(1) pointer work.

head → [1|•] → [2|•] → [3|∅] reverse: prev=null, curr=head next = curr.next; curr.next = prev; prev = curr; curr = next
JavaScript
class ListNode {
  constructor(val, next = null) {
    this.val = val;
    this.next = next;
  }
}

class LinkedList {
  constructor() { this.head = null; }

  push(val) {
    const node = new ListNode(val);
    if (!this.head) { this.head = node; return; }
    let t = this.head;
    while (t.next) t = t.next;
    t.next = node;
  }

  reverse() {
    let prev = null, curr = this.head;
    while (curr) {
      const next = curr.next;
      curr.next = prev;
      prev = curr;
      curr = next;
    }
    this.head = prev;
  }
}

function detectCycle(head) {
  let slow = head, fast = head;
  while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow === fast) return true;
  }
  return false;
}

function reverseList(head) {
  let prev = null, curr = head;
  while (curr) {
    const next = curr.next;
    curr.next = prev;
    prev = curr;
    curr = next;
  }
  return prev;
}
Dummy node. const dummy = new ListNode(0, head) so you never special-case ‘new head.’ Essential for remove-nth-from-end and merge.
JavaScript
function mergeTwo(a, b) {
  const dummy = new ListNode(0);
  let t = dummy;
  while (a && b) {
    if (a.val <= b.val) { t.next = a; a = a.next; }
    else { t.next = b; b = b.next; }
    t = t.next;
  }
  t.next = a || b;
  return dummy.next;
}

Implement: middle and remove nth from end

JavaScript
function middleNode(head) {
  let slow = head, fast = head;
  while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;
  }

}

function removeNthFromEnd(head, n) {
  const dummy = new ListNode(0, head);
  let fast = dummy, slow = dummy;
  for (let i = 0; i < n + 1; i++) fast = fast.next;
  while (fast) { fast = fast.next; slow = slow.next; }
  slow.next = slow.next.next;
  return dummy.next;
}

Stacks and queues

Stack = last in, first out

Use an array: push / pop / at(-1). Do not shift.

JavaScript
function validParentheses(s) {
  const st = [];
  const pair = { ")": "(", "]": "[", "}": "{" };
  for (const ch of s) {
    if (ch === "(" || ch === "[" || ch === "{") st.push(ch);
    else {
      if (st.pop() !== pair[ch]) return false;
    }
  }
  return st.length === 0;
}

class MinStack {
  constructor() { this.st = []; this.mins = []; }
  push(x) {
    this.st.push(x);
    const m = this.mins.length ? this.mins[this.mins.length - 1] : Infinity;
    this.mins.push(Math.min(m, x));
  }
  pop() { this.st.pop(); this.mins.pop(); }
  top() { return this.st[this.st.length - 1]; }
  getMin() { return this.mins[this.mins.length - 1]; }
}

Product: undo stack, browser history (back), DFS, parsing, call stack (the real one).

Queue = first in, first out

arr.shift() is O(n). For interview BFS on small n it is acceptable if you say so. From scratch, keep a head index or a linked list.

JavaScript
class Queue {
  constructor() { this.a = []; this.h = 0; }
  enqueue(x) { this.a.push(x); }
  dequeue() {
    if (this.h >= this.a.length) return undefined;
    const x = this.a[this.h++];
    if (this.h > 32 && this.h * 2 > this.a.length) {
      this.a = this.a.slice(this.h);
      this.h = 0;
    }
    return x;
  }
  get size() { return this.a.length - this.h; }
}

Product: job queues, BFS, event batching, “print next / serve next.”

Deque (two ends): JS has no deque. Use an array + two indices, or two stacks. For sliding-window maximum, a monotonic deque is the expert move (see Expert structures).

The stack you cannot see

Recursion

Recursion is the call stack doing a stack’s job

Every call pushes a frame. A base case stops. Without it you get RangeError: Maximum call stack size exceeded.

JavaScript
function fact(n) {
  if (n <= 1) return 1;
  return n * fact(n - 1);
}

function fibNaive(n) {
  if (n <= 1) return n;
  return fibNaive(n - 1) + fibNaive(n - 2); // O(2^n)
}

function fibMemo(n, memo = new Map()) {
  if (n <= 1) return n;
  if (memo.has(n)) return memo.get(n);
  const v = fibMemo(n - 1, memo) + fibMemo(n - 2, memo);
  memo.set(n, v);
  return v;
}

function flatten(arr) {
  const out = [];
  for (const x of arr) {
    if (Array.isArray(x)) out.push(...flatten(x));
    else out.push(x);
  }
  return out;
}
fib(4) fib(3) fib(2) fib(2) fib(1) fib(1) fib(0) Memo: each n computed once → O(n)

Think “smallest version of the same problem.” Trees and backtracking are recursion with a structure. DP is recursion with a cache, then a table.

function preorder(root, out = []) {

  out.push(root.val);

function levelOrder(root) {
  if (!root) return [];
  const q = [root], res = [];
  while (q.length) {
    const n = q.length, level = [];
    for (let i = 0; i < n; i++) {
      const node = q.shift();
      level.push(node.val);
      if (node.left) q.push(node.left);
      if (node.right) q.push(node.right);
    }
    res.push(level);
  }
  return res;
}

function maxDepth(root) {
  if (!root) return 0;
  return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}

BFS (queue, levels): shortest path in unweighted trees/grids, serialize by level. DFS (stack/recursion): path problems, height, “does a root-to-leaf sum exist.”

BST: left < node < right

JavaScript
function bstSearch(root, t) {
  let n = root;
  while (n) {
    if (n.val === t) return n;
    n = t < n.val ? n.left : n.right;
  }
  return null;
}
function bstInsert(root, val) {
  if (!root) return new TreeNode(val);
  if (val < root.val) root.left = bstInsert(root.left, val);
  else root.right = bstInsert(root.right, val);
  return root;
}

Average search O(log n) if balanced; worst O(n) if you insert sorted data into a naive BST. Interviews often ignore self-balancing (AVL/red-black) unless asked — say “I’d use a balanced tree or a Map.”

Priority

Heaps

A heap is a complete tree stored in an array

JS has no PriorityQueue in the language. You write a binary heap or sort (O(n log n)) when n is small.

Index: parent (i-1)>>1, children 2i+1, 2i+2. Min-heap: parent ≤ children.

JavaScript
class MinHeap {
  constructor() { this.a = []; }
  peek() { return this.a[0]; }
  push(x) {
    this.a.push(x);
    this._up(this.a.length - 1);
  }
  pop() {
    const a = this.a;
    if (a.length === 0) return undefined;
    const top = a[0];
    const last = a.pop();
    if (a.length) { a[0] = last; this._down(0); }
    return top;
  }
  _up(i) {
    const a = this.a;
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (a[p] <= a[i]) break;
      [a[p], a[i]] = [a[i], a[p]];
      i = p;
    }
  }
  _down(i) {
    const a = this.a, n = a.length;
    while (true) {
      let s = i, l = i * 2 + 1, r = l + 1;
      if (l < n && a[l] < a[s]) s = l;
      if (r < n && a[r] < a[s]) s = r;
      if (s === i) break;
      [a[s], a[i]] = [a[i], a[s]];
      i = s;
    }
  }
}

function topK(nums, k) {
  const h = new MinHeap();
  for (const x of nums) {
    h.push(x);
    if (h.a.length > k) h.pop();
  }
  return h.a.slice();
}

Push/pop O(log n). Build from n items O(n) if you heapify (optional expert). Product: schedulers, “top 10,” Dijkstra, merge k lists.

Networks

Graphs

A graph is nodes plus edges

Prefer an adjacency list: Map<node, node[]> or number[][]. A matrix is O(n²) space — use it when the graph is dense or a grid already is a matrix.

JavaScript
class Graph {
  constructor() { this.adj = new Map(); }
  addNode(u) { if (!this.adj.has(u)) this.adj.set(u, []); }
  addEdge(u, v, directed = false) {
    this.addNode(u); this.addNode(v);
    this.adj.get(u).push(v);
    if (!directed) this.adj.get(v).push(u);
  }
}

function bfs(adj, start) {
  const seen = new Set([start]);
  const q = [start];
  const order = [];
  while (q.length) {
    const u = q.shift();
    order.push(u);
    for (const v of adj.get(u) || []) {
      if (!seen.has(v)) { seen.add(v); q.push(v); }
    }
  }
  return order;
}

function dfs(adj, start, seen = new Set(), order = []) {
  seen.add(start);
  order.push(start);
  for (const v of adj.get(start) || []) {
    if (!seen.has(v)) dfs(adj, v, seen, order);
  }
  return order;
}
BFS: queue, visit nearest first — shortest hops DFS: stack/recursion — explore a path all the way

A grid is a graph with four neighbors

JavaScript
function numIslands(grid) {
  const R = grid.length, C = grid[0]?.length || 0;
  const dirs = [[1,0],[-1,0],[0,1],[0,-1]];
  function sink(r, c) {
    if (r < 0 || c < 0 || r >= R || c >= C || grid[r][c] !== "1") return;
    grid[r][c] = "0";
    for (const [dr, dc] of dirs) sink(r + dr, c + dc);
  }
  let n = 0;
  for (let r = 0; r < R; r++)
    for (let c = 0; c < C; c++)
      if (grid[r][c] === "1") { n++; sink(r, c); }
  return n;
}

Visited: mutate the grid, or a Set of `${r},${c}`. BFS if you need distance (shortest path in a maze).

Directed graphs: cycles and order

JavaScript
function canFinish(n, prereqs) {
  const adj = Array.from({ length: n }, () => []);
  const indeg = Array(n).fill(0);
  for (const [a, b] of prereqs) { adj[b].push(a); indeg[a]++; }
  const q = [];
  for (let i = 0; i < n; i++) if (indeg[i] === 0) q.push(i);

    const u = q.shift();
    seen++;
    for (const v of adj[u]) if (--indeg[v] === 0) q.push(v);

Order

Sorting and search

Sort when you must; binary search when it’s sorted

arr.sort((a,b) => a-b) is O(n log n). Never sort() without a comparator on numbers (it sorts as strings).

JavaScript
function mergeSort(arr) {
  if (arr.length <= 1) return arr;
  const m = arr.length >> 1;
  return merge(mergeSort(arr.slice(0, m)), mergeSort(arr.slice(m)));
}
function merge(a, b) {
  const out = [];
  let i = 0, j = 0;
  while (i < a.length && j < b.length)
    out.push(a[i] <= b[j] ? a[i++] : b[j++]);
  return out.concat(a.slice(i), b.slice(j));
}

function binarySearch(a, t) {
  let lo = 0, hi = a.length - 1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    if (a[mid] === t) return mid;
    if (a[mid] < t) lo = mid + 1;
    else hi = mid - 1;
  }
  return -1;
}

/** first index where pred(i) is true (pred is monotonic) */
function lowerBound(n, pred) {
  let lo = 0, hi = n;
  while (lo < hi) {
    const mid = (lo + hi) >> 1;
    if (pred(mid)) hi = mid;
    else lo = mid + 1;
  }
  return lo;
}

Binary search on answer (min days, min capacity) uses the second template. The predicate must flip from false to true once.

function twoSumSorted(a, target) {
  let lo = 0, hi = a.length - 1;
  while (lo < hi) {
    const s = a[lo] + a[hi];
    if (s === target) return [lo, hi];

function maxArea(h) {
  let lo = 0, hi = h.length - 1, best = 0;
  while (lo < hi) {
    best = Math.max(best, Math.min(h[lo], h[hi]) * (hi - lo));
    if (h[lo] < h[hi]) lo++;

}

function coinChange(coins, amount) {

Union-find: growing components

JavaScript
class UnionFind {
  constructor(n) { this.p = [...Array(n).keys()]; this.r = Array(n).fill(0); }
  find(x) {
    if (this.p[x] !== x) this.p[x] = this.find(this.p[x]);
    return this.p[x];
  }
  union(a, b) {
    a = this.find(a); b = this.find(b);
    if (a === b) return false;
    if (this.r[a] < this.r[b]) [a, b] = [b, a];
    this.p[b] = a;
    if (this.r[a] === this.r[b]) this.r[a]++;
    return true;
  }
}

class LRUCache {
  constructor(capacity) { this.cap = capacity; this.map = new Map(); }
  get(key) {
    if (!this.map.has(key)) return -1;
    const v = this.map.get(key);
    this.map.delete(key);
    this.map.set(key, v);
    return v;
  }

    if (this.map.has(key)) this.map.delete(key);
    this.map.set(key, value);

  }

1. Why is unshift O(n) in JavaScript?

Short answer. It inserts at index 0, so every existing element must move one slot right.

Deep explanation. An array is a contiguous index map 0..length-1. unshift writes a new 0 and reindexes the rest. push writes at length and (usually) does not move anyone — amortized O(1). Never build a list with repeated unshift in a hot loop; push then reverse, or use a deque.

Common misconception. unshift is O(1) because it is a built-in.

Senior follow-up. How would you implement a queue so both ends are cheap?

Short answer. Same recurrence dp[i][j] = from-above + from-left, but obstacles stay 0 and do not contribute.

Deep explanation. First row/col must stop filling after the first wall. Rolling 1D array: walk left-to-right, dp[j] += dp[j-1], zero on obstacle. This is the 'I can compress' flex.

Common misconception. Obstacles need DFS only.

            Language

            Glossary

            Adjacency list

            Graph as node → list of neighbors. Default for sparse graphs.

            Amortized O(1)

            Average cost per op if expensive resizes are rare (e.g. push).

            BFS

            Queue. Level by level. Shortest hops on unweighted graphs.

            Binary search

            Halve a sorted range. Watch lo/hi and mid overflow.

            BST

            Left < node < right (consistent with equals policy). Height is not automatically log n.

            Backtracking

            Choose, recurse, unchoose. Copy the path when you store a result.

            Big O

            Growth of worst-case work (or space) as n grows.

            Cycle (Floyd)

            Two pointers at different speeds meet if a list loops.

            DFS

            Stack or recursion. Paths, components, topo via postorder.

            Dummy node

            Fake list head so insert/merge never special-cases the first real node.

            Heap (binary)

            Array-backed complete tree. Children at 2i+1 and 2i+2.

            Indegree

            Count of incoming edges. Kahn starts at indegree 0.

            Kadane

            Best subarray ending here = max(x, prevEnding + x).

            Kahn

            Topo sort by peeling indegree-0 nodes. leftover nodes ⇒ cycle.

            LRU

            Evict least recently used. Map insertion order, or Map + doubly linked list.

            Memoization

            Top-down DP: cache answers to a named state.

            Monotonic stack

            Indexes whose values stay increasing or decreasing. Next-greater family.

            Prefix sum

            pref[i] = sum of first i. Range = pref[r] − pref[l].

            Sliding window

            Two indexes that only move forward. Fixed k or shrink while invalid.

            Tabulation

            Bottom-up DP. Loops from base cases, often rollable.

            Topological order

            A before B if A must happen first. DAG only.

            Trie

            Prefix tree. Each edge is a character. startsWith is O(length).

            Two pointers

            Lo/hi or slow/fast. Needs an invariant (sorted, or partition).

            Union-find

            Disjoint sets. find(root) + union. Path compression + rank ≈ O(1).

            Visited

            Mark when first seen (usually enqueue) so BFS/DFS do not explode.
